## 本機預覽

安裝 Node.js 後，在此資料夾執行 `node preview-server.mjs`，開啟 http://localhost:4188/。請透過 HTTP 開啟，直接點 index.html 可能無法載入模組。後台為 `internal.html`，文件為 `documents.html`。

## 展示重點

- 綠色「申貸流程與文件」入口，獨立六步流程與收合文件清單。
- 四類需求：營運週轉金、展店開張、海外拓店與匯率、中央廚房設備。
- 加盟飲料、加盟餐飲、自主品牌與一般企業範例；所有數字為教學假設。
- 五種財務健檢情境，包含虧損與薄利情境，搭配獲利圖表。
- 規劃 Excel 含喵喵封面、原始數字、摘要及文件清單。
- 首頁底部諮詢表單，把需求、型態、聯繫偏好、已更新試算與健檢保存為同一筆案件；送出後可直接開啟後台該筆內容。
- 小型收付通／全球智匯網入口；移除企業查詢區。
- 後台地址地圖、候選據點與可調整的金額分派規則。

## 建議演示順序

1. 選展店與開張 → 加盟飲料第一間店 → 更新試算。融資需求 330 萬，另列每月營運餘額。
2. 帶入一個健檢情境 → 查看獲利圖。
3. 文件頁勾選已備妥項目 → 回首頁查看摘要 → 下載喵喵 Excel。
4. 底部帶入示範需求 → 確認附上試算 → 勾選同意 → 建立案件 → 查看後台這筆需求。
5. 後台據點區帶入 600 萬示範門檻並儲存；此例建議分行。中央廚房 3,500 萬例可演示區域中心。
6. 分派仍需人工確認。示範規則不是玉山授信內規或正式服務權責。

## 分派金額

週轉使用新增資金缺口；設備使用投資減自有資金；展店使用建置費＋週轉準備－自有資金。不得將年度還款或每月盈餘當作需求金額。海外使用已含匯率壓力及預備金的台幣等值缺口。金額未知或門檻未設定則待人工確認。
