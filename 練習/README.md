## 個人進度

每個人的錯題、收藏、作答統計、成績與未完成考卷只儲存在目前裝置的瀏覽器 localStorage，不上傳雲端。延用 steven-study-v1，保留既有本機紀錄。不同手機、瀏覽器或網址各自獨立；清除網站資料、無痕模式或更換裝置可能遺失紀錄。可用「匯出進度／匯入進度」備份與搬移。

雲端同步已關閉；舊雲端資料未刪除，但此版本不再讀寫。GitHub Pages與Sites均使用本機模式。

## 內容與部署

公開版本僅提供衍生考題與解析，不含原始講義PDF、照片、個人作答紀錄或憑證。來源名稱與頁碼供讀者核對自己的講義。
