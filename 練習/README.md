# 銀行考前練習室

449 題題庫，含 60 題中文財金與匯率題、30 題金融英文。

## 使用

純靜態 HTML / CSS / JavaScript。用任一靜態伺服器提供此目錄，例如：

```bash
python -m http.server 8000
```

瀏覽器開啟 http://localhost:8000 。請勿只用 file:// 直接打開，因為題庫透過 fetch 載入。

- 模擬考：45 題單選、5 題複選；包含5題英文。
- 中文10科各4至5題；另可選55題模式。
- 重點加強：20題，每中文科2題，含2題複選。
- 支援分科、匯率主題、錯題、收藏、進度匯出與匯入。
- 作答紀錄僅保存在目前瀏覽器，不會自動跨裝置同步。
